# Dracarys
A simple browser clicker game built around the dragons of *A Song of Ice and Fire*. Click to earn gold, spend it to hatch dragons, and collect them all.
 
## How it works
 
- Click to earn gold.
- Spend gold to hatch a random dragon (weighted by rarity: common / rare / legendary).
- Collected dragons are tracked and displayed as you unlock them.
## Tech
 
- HTML / CSS / JavaScript (no frameworks)
- Dragon data stored in `data/dragons.json`
## Running it
 
Just open `index.html` in a browser, or use a local server (e.g. VS Code's Live Server extension) for the best experience.
 
## Data
 
Dragon info in `data/dragons.json` includes name, epithet, rarity, era, riders, and a short description, all drawn from ASOIAF / Fire & Blood canon.
